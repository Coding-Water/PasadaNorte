## Numbered Findings

### HIGH Priority (Hard Gate)

1. **[R-37] Missing `DESIGN.md` across both clients**
   - **Location:** Project root (`PasadaNorte/DESIGN.md` absent prior to this audit)
   - **Reason:** Neither `mobile_client` nor `web_client` had a `DESIGN.md` defining brand direction, dials, or palette tokens, causing `mobile_client` (`#007A37` vs `#00C466`) and `web_client` (`#059669` + 65 ad-hoc colors) to drift into inconsistent defaults.

2. **[R-25] White text on `#00C466` and `#059669` fails WCAG AA contrast**
   - **Location:** `mobile_client/lib/features/auth/views/welcome_onboarding_screen.dart:21`, `mobile_client/lib/features/rider/views/passenger_service_hub_screen.dart:211`, `web_client/lib/main.dart:42-43`
   - **Reason:** `#FFFFFF` on `#00C466` measures **2.31:1** (fails both 4.5:1 normal and 3.0:1 large text) and `#FFFFFF` on `#059669` measures **3.77:1** (fails 4.5:1 normal text), whereas `AppTheme.accentEmerald` (`#007A37`) passes at **5.47:1**.

3. **[R-25] Low-contrast muted greys and amber on white surfaces**
   - **Location:** `mobile_client/lib/features/rider/views/passenger_service_hub_screen.dart:91` (`Colors.grey.shade400` `#BDBDBD`), `web_client/lib/main.dart` (`0xFF94A3B8`, `0xFFF59E0B` on white)
   - **Reason:** `#BDBDBD` on `#FFFFFF` is **1.88:1**, `#94A3B8` on `#FFFFFF` is **2.56:1**, and `#F59E0B` on `#FFFFFF` is **2.15:1**, all failing WCAG AA 4.5:1 (text) and 3.0:1 (non-text icons/UI).

4. **[R-02] Em dash (`—`) used in UI strings and HTML metadata**
   - **Location:**
     - `web_client/web/index.html:21` (`PasadaNorte Command Center — Laoag City...`)
     - `web_client/lib/main.dart:36, 565, 632, 635, 637, 822, 830, 1012, 1028, 1051, 1411, 1527-1531, 1547, 1598, 2391, 3640, 3773, 4052, 4125, 4892, 5038`
     - `mobile_client/lib/features/driver/views/driver_account_screen.dart:237, 238, 541`
     - `mobile_client/lib/features/rider/views/passenger_account_screen.dart:719, 722-724, 767`
   - **Reason:** R-02 forbids the em dash character (`—`) in any UI text, including empty-value placeholders (`'—'` should be `'-'` or `'Not set'`) and status banners.

5. **[R-03] Unresponsive fixed 260px sidebar in `web_client` breaks narrow/mobile viewports**
   - **Location:** `web_client/lib/main.dart:2469-2473`
   - **Reason:** `Scaffold.body` uses an unconditional `Row` with a fixed `width: 260` sidebar and no `MediaQuery` breakpoint or `Drawer` fallback, leaving only 115px on a 375px viewport and causing horizontal overflow/clipping.

6. **[R-39] Missing `<html lang>` attribute in `web_client/web/index.html`**
   - **Location:** `web_client/web/index.html:2` (`<html>`)
   - **Reason:** R-39 requires `<html lang="en">` on whole HTML documents so screen readers and translation tools identify the document language.

7. **[R-32 / R-39] Zero `Semantics` annotations in `web_client`**
   - **Location:** `web_client/lib/main.dart` (0 `Semantics(` occurrences across 12,528 lines)
   - **Reason:** Custom `InkWell`/`GestureDetector` cards, map pins, status pills, and icon-only controls lack explicit `Semantics` labels/roles for assistive technology and keyboard navigation parity.

8. **[R-03] Under-sized tap targets (< 44x44 px) in `mobile_client`** *(antislop-layoutmobile)*
   - **Location:** `mobile_client/lib/features/driver/views/driver_active_trip_screen.dart:3011` (`minWidth: 18, minHeight: 18`), `mobile_client/lib/features/rider/views/live_ride_tracking_screen.dart:3131` (`minWidth: 18, minHeight: 18`), `mobile_client/lib/features/rider/views/rider_map_booking_screen.dart:1057-1058` (`minWidth: 32, minHeight: 32`, `padding: EdgeInsets.zero`)
   - **Reason:** Interactive icon buttons are constrained below the 44x44 px minimum touch target, making them difficult to tap reliably on mobile screens.

9. **[R-03] Two-state grid layout cliff in `web_client` dashboard** *(antislop-layoutmobile)*
   - **Location:** `web_client/lib/main.dart:3126-3137` (`final isWide = constraints.maxWidth > 900; crossAxisCount: isWide ? 3 : 1;`)
   - **Reason:** Layout jumps directly from 3 columns to 1 column with no 2-column intermediate state for tablet/small-laptop widths (`600-900px`), stretching single-column cards overly wide.

10. **[R-39] `GestureDetector` controls in `web_client` lack pointer cursor and `Semantics`** *(antislop-ui)*
    - **Location:** `web_client/lib/main.dart:2851, 3764, 7093, 8269`
    - **Reason:** Interactive `GestureDetector` badges/controls (e.g., Live SOS badge at line 2851) do not wrap in `MouseRegion(cursor: SystemMouseCursors.click)` or `Semantics(button: true)`.

11. **[R-03] `web_client` sidebar items under 44px height with no collapse/mobile trigger** *(antislop-ui / antislop-layoutmobile)*
    - **Location:** `web_client/lib/main.dart:12162-12206` (`_buildSidebarItem` has `vertical: 9` + `19px` icon = ~37px height)
    - **Reason:** Sidebar rows fall below the 44px touch target on tablets/touchscreens, and the shell lacks a collapse toggle and mobile `Drawer` trigger.

### MEDIUM Priority (Purpose-Gate)

12. **[R-06] Orphaned `fontFamily: 'Inter'` without asset or brand rationale**
    - **Location:** `web_client/lib/main.dart:40`, `mobile_client/lib/features/auth/views/phone_input_screen.dart:369`, `mobile_client/lib/core/theme/app_theme.dart`
    - **Reason:** `Inter` is declared in `web_client` and in one isolated `TextStyle` in `mobile_client`, while `app_theme.dart` sets no `fontFamily` and `web_client/pubspec.yaml` bundles no `Inter` font files, resulting in an unreasoned AI default fallback.

13. **[R-04] Generic lightning/bolt icons used for driver duty and ID actions** *(antislop-ui)*
    - **Location:** `mobile_client/lib/features/auth/views/id_upload_screen.dart:485`, `mobile_client/lib/features/driver/views/driver_active_trip_screen.dart:2889, 2941`, `mobile_client/lib/features/driver/views/driver_map_duty_screen.dart:1545`
    - **Reason:** `Icons.bolt_rounded` and `Icons.flash_on_rounded` are used as generic action/status glyphs without a written domain reason; domain-specific icons (e.g., `Icons.power_settings_new_rounded`, `Icons.directions_rounded`) communicate clearer meaning.

14. **[R-04] Decorative emoji scattered across UI headings, badges, and buttons** *(antislop-ui)*
    - **Location:** `mobile_client/lib/features/auth/views/otp_verification_screen.dart:327` (`🔐`), `mobile_client/lib/features/driver/views/driver_map_duty_screen.dart:651, 672` (`💵`, `📱`), `mobile_client/lib/features/rider/views/live_ride_tracking_screen.dart:3834, 3840, 3845` (`⏳😄`, `🔥`), `web_client/lib/main.dart:2560, 2883, 3555, 5362, 11886, 12085` (`🚨`, `🔒`, `✅`)
    - **Reason:** Literal emoji in operational labels and buttons compete with content and should be replaced with purposeful Material/semantic icons or plain text.

15. **[R-12] Ad-hoc `BoxShadow` elevation across map/trip widgets without a shared elevation scale** *(antislop-ui)*
    - **Location:** `mobile_client/lib/features/driver/views/driver_active_trip_screen.dart:1569, 2027, 2063, 2200, 2355, 2424, 2495, 3077, 3132`, `mobile_client/lib/features/driver/views/driver_map_duty_screen.dart:1394, 1418, 1455, 1537, 1580, 1609`
    - **Reason:** Multiple cards, pills, and floating buttons define custom `BoxShadow`s (`black12`, `black26`, `black38`, varying blur radii) rather than a documented 2-level elevation hierarchy.

16. **[R-01] Uncentralized `LinearGradient` hero card using low-contrast green** *(antislop-ui)*
    - **Location:** `mobile_client/lib/features/rider/views/passenger_service_hub_screen.dart:210-214`, `mobile_client/lib/features/driver/views/driver_activity_screen.dart:329`, `mobile_client/lib/features/driver/views/driver_map_duty_screen.dart:603`
    - **Reason:** Gradients use `#00C466` -> `#059669` instead of the WCAG-compliant `AppTheme.accentEmerald` (`#007A37`) -> `#065F46`, and lack a documented hierarchy rationale.

17. **[R-19 / R-39] Endless radar pulse animation without reduced-motion guard** *(antislop-ui)*
    - **Location:** `mobile_client/lib/features/rider/views/live_ride_tracking_screen.dart:118-121` (`..repeat(reverse: true)`)
    - **Reason:** Continuous looping animation runs unconditionally without checking `MediaQuery.disableAnimationsOf(context)` (`prefers-reduced-motion`) or matching a declared `MOTION` purpose.

    - **Reason:** Dozens of ad-hoc greens, blues, purples (`0xFF7E22CE`, `0xFF8B5CF6`), ambers, oranges, and slates are hardcoded inline instead of a disciplined 2-3 core + 1 accent + semantic token system.

## Follow-Up Fix & Delivery Gate Report (2026-11-19)

### Changes Applied
- **`DESIGN.md` (#1, R-37):** Created project-wide design direction, liveliness dials, WCAG-verified color tokens, typography scale, and radius/elevation rules.
- **Color & Contrast (#2, #3, #16, #18, R-01, R-25, R-29):** Created `web_client/lib/theme/web_theme.dart` and updated `mobile_client/lib/core/theme/app_theme.dart` with WCAG AA compliant `brandEmerald` (`#007A37`, 5.47:1 on white) and `inkMuted` (`#64748B`, 4.76:1 on white); replaced `#00C466`, `#059669`, `#BDBDBD`, and `#94A3B8` across onboarding, service hub, driver duty/activity, and web admin views.
- **Em Dashes (#4, R-02):** Replaced all `—` characters in `web_client/web/index.html`, `web_client/lib/main.dart`, `driver_account_screen.dart`, and `passenger_account_screen.dart` with `-`.
- **Responsive Web Shell & Grid (#5, #9, #11, R-03):** Refactored `web_client/lib/main.dart` to collapse the sidebar into a `Drawer` below `1024px`, added a desktop sidebar collapse toggle (`260px` <-> `76px`), raised sidebar item height to `>= 44px`, and replaced the `3:1` grid cliff with a 3-state responsive grid (`3 / 2 / 1` columns).
- **Accessibility & Semantics (#6, #7, #10, #17, R-19, R-32, R-39):** Added `lang="en"` to `web_client/web/index.html`, added `Semantics` to web sidebar items, menu trigger, and SOS badge with `MouseRegion(cursor: SystemMouseCursors.click)`, and guarded `live_ride_tracking_screen.dart`'s radar pulse animation with `disableAnimations`.
- **Mobile Tap Targets (#8, R-03):** Raised `18x18` and `32x32` icon button constraints in `driver_active_trip_screen.dart`, `live_ride_tracking_screen.dart`, and `rider_map_booking_screen.dart` to `44x44`.
- **Typography, Icons, Emoji & Copy (#12, #13, #14, #15, #19, #20, #21, #23, #24, R-04, R-05, R-06, R-11, R-12, R-14, R-15, R-16, R-26, R-30):** Removed orphaned `fontFamily: 'Inter'` declarations, replaced generic bolt/flash icons with domain icons, removed decorative emoji from operational UI strings, renamed `_buildKrispMetricCard` to `_buildOperationalMetricCard`, standardized `level1Shadow` and radius tokens, replaced `"Let's Get Started"` / `"Seamless Transactions"` (leaving R-38 vehicle text untouched), and added a `// TODO` on the coming-soon e-wallet tile.
- **Dark Mode (#22, R-21):** Added `darkTheme` and `themeModeNotifier` in both `AppTheme` and `WebTheme`, plus a live theme toggle in the web sidebar footer.
